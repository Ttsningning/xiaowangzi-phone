# 星页书房 · 接入记录

开发基线：`feature/star-library-and-image-presets`。按宁宁 2026-11-16 的确认，完成检查后接入 main。当前范围为 TXT / DOCX 导入、当前设备阅读进度、三种协作写作与 NAI 多预设；EPUB / PDF、跨设备同步暂不需要。

## 功能

- 使用宁宁提供的透明 PNG 图标：主图、共读、共写、书架、共同作品、空书架；原图保持透明，CSS 分区显示。
- TXT / DOCX 本地读取；支持 UTF-8、UTF-16 和常见 GB18030 TXT；章节识别及长文本分段；DOCX 识别一级/二级标题，提取纯正文，不执行文档内容。
- 文档限 8MB、正文限 200 万字、最多 500 章；旧 `.doc` 需另存为 `.docx`。Word 解压需要浏览器支持 DecompressionStream 的 deflate-raw；不支持时提示改用 TXT。
- 阅读章节与页内滚动自动保存；退出书房、切后台时立即提交保存，章节重绘期间忽略临时滚动，重开回到各章节保存的位置。书签、字号、奶油/淡紫/夜读纸张；章节讨论可折叠，支持选句带入问题。发送给 AI 的只有当前和之前章节的有限上下文，不带未来章节；这不保证模型对自己熟悉的作品绝不产生剧透。
- 接力、大纲、导演三模式共享同一本书，分开保存输入草稿；每本书单独选择搭档，沿用角色专属 API 或公共 API，不写入角色的聊天记忆。
- AI 内容先作为候选稿，确认后追加；取消保留候选稿，可暂存后重生成，草稿夹可找回；防止重复请求和并发编辑覆盖。
- 章节编辑和 AI 追加前保存历史；恢复历史前保存当前版本；删除作品进入可找回列表；完成作品单独收纳。
- 作品导出 TXT、含正文/历史/讨论/草稿/书签的 JSON；作品 JSON 恢复为独立副本，导入限 64MB；随小手机总备份保存全部书房数据。
- 补齐脚本初始化顺序、旧桌面快捷入口、构建文件清单与离线缓存清单；保留本分支 NAI 生图预设功能。

## 验证

`npm test`：现有小手机回归和 `tests/star-library.cjs`。补充章节重绘、立即关闭、持久化重新载入、逐章恢复位置，以及 NAI 旧配置迁移、复制、切换、持久化与实际请求体检查。AI 请求使用模拟响应，不消耗用户接口额度。

运行 `npm run build`，确认 dist 内含 star-library.js / css 和插画。

本轮通过 JSDOM + IndexedDB 检查压缩 DOCX 导入、章节切换、创作模式、输入保存和备份恢复。尝试启动 Chromium 受到运行环境 socket 限制，未完成本轮浏览器视觉检查，也未在真实 iPhone 或真实付费 AI 接口上验收。

## 接入方式

确认分支相对 main 无落后提交后，将 NAI 预设与书房同批合并。书房当前是浏览器本地数据，不包含多设备实时协作或云同步。
