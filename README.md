# 小王子小手机

宁宁的小手机新版。从 `Ttsningning/moonsea-phone` 的 `11a2c995b7914f237d22accf9304f18a6305492d` 完整复制原有程序、图片、主题、2048 与《登临》。月光海的主版本不做修改；后续功能在此仓库开发。

## 两个版本同时打开

- 旧版本：月光海仓库原来的网页，保持原样。
- 新版本：本仓库开启 GitHub Pages 后，使用本仓库自己的网页地址。
- 新版数据库为 `xiaowangzi-phone`，桌面图标偏好与 2048 存档也使用独立名称。两边不会互相覆盖聊天记录或游戏进度。
- 如需接着旧故事玩：在月光海「设置」导出备份，再到小王子「设置」导入。导入操作只改变新版数据。备份不包含 API 密钥；请在新版重新填写需要的密钥。

## 本版新增

- 钱包：收入/支出流水、按月汇总和图表、手动收入、每月固定收入与离线补记、自定义货币名称。
- 「bb 帮你想想」：结合用户身份与世界书推荐收入，勾选后加入固定收入。
- TA 钱包：查手机中的独立钱包页，生成后保存角色账单，可偷偷塞钱；网页运行时或重新打开后，角色延迟发现。
- 背包：收取 `[信物:名称:描述]`；使用商品或送给角色。信物可换物，不可换钱。
- 万界杂货铺：不同世界商人、急售/溢价/随缘开价、平台汇率、以物换物、紧急求购、库存、预售、订单和交易动态。
- 旧挂单持续保存；普通卖单久挂逐步降价，其他买家的模拟成交会减少库存；预售到期入包。刷新摊位调用一次聊天 API。
- 新图标直接显示素材轮廓，不叠加外层圆角底板。

所有余额、商品、买家和交易均为虚构世界内的内容，不涉及真实支付。市场与定时任务由页面驱动；关闭网页后不持续运行，下次打开按时间补算。

## 开启网页

在本仓库 **Settings → Pages** 中，将 **Source** 选为 **Deploy from a branch**，选择 **main / (root)** 并保存。GitHub 完成部署后会在该页给出独立访问链接。旧仓库无需改动。

## 开发与验证

静态 HTML/JS，无需打包，任意静态服务器均可运行。

```sh
npm install
npm test
python -m http.server 8123
```

集成检查使用 JSDOM 与内存 IndexedDB，覆盖启动、新页面渲染、余额校验、流水、旧存档迁移、固定收入补记及幂等、预售交付及幂等、信物收取、批量购买、以物换物与禁止信物变现。外部 AI 接口和真实 iOS 浏览器外观需使用自己的接口与手机验收。
