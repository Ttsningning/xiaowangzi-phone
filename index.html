语音

语音生成一次会存下来，重复播放不再花钱。每个角色的音色在「角色」里单独设。

活人感

小手机开着时，TA 到点会直接发来消息；关着的时候，下次打开会收到 TA 这段时间发的消息。你一直没回的话，TA 最多连着找你两次。

识图（看懂你发的照片）

发照片时会先让这个模型看一眼、写下照片内容，TA 就是靠这段描述「看」照片的。主体模型不支持看图的话（比如 DeepSeek），这里要单独填一个能看图的模型。

生图（TA 拍照片 · 剧情配图）

固定种子填 0—4294967295 的整数。
NAI 只认英文 tag：TA 拍照、剧情配图时，会先用主体 AI 把画面翻成 tag 再交给 NAI。
不填生图模型也能玩：TA 发的照片会变成「文字照片」卡片。角色长什么样，在「角色」里的「外貌」填，生图时会带上。

备份到 GitHub

令牌只存在你手机里，备份文件里不会带任何密钥。语音缓存不备份（需要时会重新生成）。

其他

备份不包含 API 密钥。所有数据只存在这台设备的浏览器里。
